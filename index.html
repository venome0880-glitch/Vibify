Features

Everything a music bot should do.

Built component-first, so every control lives right on the player card.

Now-playing cards

Artwork plus previous, pause, skip, stop, loop and autoplay buttons on one clean card.

Voice channel status

The current track and playback mode appear automatically as the channel status.

Six sources

YouTube, YouTube Music, Spotify, Apple Music, Deezer and JioSaavn search.

Favourites & history

Like songs, replay your liked list, browse history and build playlists.

Audio filters

Shape the sound with filters, speed and volume controls.

/filter/speed/volume

Queue control

Move, remove, shuffle, skip to a spot, seek, forward and rewind.

/queue/move/remove/shuffle/skipto/seek/forward/rewind

Per-server settings

Prefix, ignored channels and sources stored per server in MongoDB.

Self-host in minutes.

  1. Install Node.js 20.18.1 or newer
  2. Run MongoDB and a Lavalink v4 node
  3. Enable the Server Members, Presence and Message Content intents
  4. Copy .env.example to .env and add your token
  5. Run npm install, then npm start
